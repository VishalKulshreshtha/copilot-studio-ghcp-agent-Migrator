# Packages

Use the package that matches your runtime.

| Package | Use for | How to use |
| --- | --- | --- |
| `ghcp-agent-migrator-code.zip` | Copilot Code / Code tab | Unzip into the Code workspace or repository root, then run `/ghcp-agent-migrator <Copilot Studio source agent URL>`. |
| `ghcp-agent-migrator-cowork.zip` | Cowork cloud app upload | Upload the ZIP directly as the Cowork/Teams-style app package. |

Do not upload the Code ZIP as a Cowork app. Do not unzip the Cowork ZIP into Code.
