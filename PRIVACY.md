# Privacy

This package does not run a hosted backend service.

However, when used in Microsoft Scout, Copilot Code, Copilot Studio, or another host, prompts, source-agent summaries, generated artifacts, and any inspected files may be processed by that host and its configured services. The host's privacy, compliance, data handling, and retention policies apply.

Do not include secrets, credentials, or unnecessary customer data in prompts or generated files.
